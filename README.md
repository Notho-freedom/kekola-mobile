# Kekola Mobile

Mobile application for Kekola with dedicated backend services and client-server architecture.

## 🚀 Features

- 📱 **Mobile app** - Cross-platform mobile application
- 🔄 **Real-time sync** - Client-server synchronization
- 🔐 **Authentication** - Secure login and user management
- 📊 **Dashboard** - Mobile-optimized interface
- 🔔 **Notifications** - Push notifications and alerts

## 🛠️ Tech Stack

- **Frontend**: Dart, Flutter
- **Backend**: Custom backend API
- **State**: Flutter state management
- **Platforms**: Android, iOS

## 📁 Project Structure

`
kekola-mobile/
├── mobile-client/     # Flutter mobile app
├── backend/           # Server-side API
├── android/           # Android native
├── ios/               # iOS native
└── pubspec.yaml
`
